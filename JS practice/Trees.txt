4. Max Depth of Binary Tree

Base Case: 
if node === null return 0
What gets smaller: current -> child
Recursive Relationship:  
                    depthLeft = 1 + maxDepth(node.left);
                    depthRight = 1  + maxDepth(node.right);
                    return depthLeft > depthRight ? depthLeft : depthRight;
Traversal Type: DFS
Return Style: Child returns depth.
Parent adds 1 for itself and returns the maximum depth.

function maxDepth(node){
  if(node === null) return 0;
  else{
    const depthLeft = 1 + maxDepth(node.left);
    const depthRight = 1 + maxDepth(node.right);
    return depthLeft > depthRight ? depthLeft : depthRight;
  }
  
}
